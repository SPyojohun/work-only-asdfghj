เริ่มต้นใช้งาน

  1. เปิดหน้า Soundboard แล้วกด Card เพื่อเล่นเสียง
  2. ใช้ปุ่ม STOP ALL เพื่อหยุดทุกเสียงพร้อมกัน
  3. ปรับระดับเสียงด้วยแถบระดับเสียงด้านล่าง

Keyboard Shortcuts

บนคอมพิวเตอร์ กดปุ่มที่แสดงบน Card เพื่อเล่นเสียงได้ทันที สามารถกดเสียงหลายรายการพร้อมกันได้ Shortcut จะไม่ทำงานขณะกำลังพิมพ์ในช่องค้นหา

เพิ่มเสียง

  1. เตรียมไฟล์ MP3 หรือ WAV แล้วใส่ในโฟลเดอร์ sounds/
  2. เปิด sounds.json แล้วเพิ่มข้อมูลเสียงหนึ่งรายการ
  3. Commit และ Push ขึ้น GitHub จากนั้นรอ GitHub Pages อัปเดต
{
  "id": "door",
  "name": "เสียงประตูปิด",
  "file": "sounds/door.mp3",
  "category": "เอฟเฟกต์",
  "shortcut": "7"
}

ลบหรือปรับ Card

ลบไฟล์ออกจาก sounds/ และลบรายการนั้นจาก sounds.json หากต้องการเปลี่ยนชื่อ หมวดหมู่ Shortcut หรือไฟล์ ให้แก้เฉพาะค่า name, category, shortcut หรือ file ในไฟล์ JSON

ใช้บนมือถือ

เปิด URL ก่อนเริ่มการแสดง แตะ Card เพื่อเล่นเสียง และใช้ปุ่ม MENU เพื่อเปิดเมนูนำทาง เบราว์เซอร์มือถือบางรุ่นจะอนุญาตเสียงหลังจากผู้ใช้แตะหน้าจอครั้งแรกเท่านั้น

แก้ปัญหาเบื้องต้น

ถ้า Card แสดง FILE NOT FOUND ให้ตรวจสอบชื่อและตำแหน่งไฟล์ใน sounds/ ให้ตรงกับ file ใน JSON หากหน้าแจ้งว่าโหลด configuration ไม่ได้ ให้ตรวจสอบ comma, quote และวงเล็บใน sounds.json
